# SafetySafar 🚨🌍

SafetySafar is an AI-powered tourist safety and emergency assistance platform designed to improve traveler safety through real-time monitoring, AI analysis, and emergency support.

## Features

- 🔐 Digital ID & KYC Verification
- 🚨 SOS Emergency Alerts
- 📍 Real-Time Location Tracking
- 🛡️ Danger Zone Detection
- 🤖 AI Safety Recommendations
- 👮 Admin & Authority Dashboard
- 📄 FIR / Incident Reporting
- ☁️ Supabase Integration

## Tech Stack

### Frontend
- Flutter
- Dart

### Backend
- FastAPI
- Python

### Database & Services
- Supabase PostgreSQL
- Firebase
- Gemini AI API
